# invoice-from-tasks

> Last reviewed: 2026-09-24

Приложение для облачного Битрикс24 **«Счёт из задач»**: заполняет товарную часть счёта по
задачам и затраченному в них времени.

## Что это

В карточке нового счёта — пункт **«Заполнить из задач»** (верхняя кнопка карточки). Дальше:

1. **Откуда задачи** — из связанной сделки или привязанные к самому счёту (не смешиваются).
2. **Как считать** — задача одной строкой по ставке ответственного, или каждая запись
   затраченного времени строкой по ставке того, кто её внёс.
3. **Предпросмотр** — строки, часы, ставки, наценки, суммы. Если в задачах чего-то не хватает,
   приложение показывает все проблемы со ссылками на задачи и **ничего не пишет**.
4. **Запись** — заменить товары счёта или добавить к ним.

В настройках: ставки сотрудников с датой начала действия, округление времени (как есть, до
часа, 30, 10 или 5 минут; вверх или к ближайшему), наценки (на всё и по тегам задач — первое
совпадение), валюта ставок (счёт в другой валюте пересчитывается по курсу портала с
предупреждением), названия строк как есть или через BitrixGPT с редактируемыми промптами,
консультации BitrixGPT по счёту — ответ сохраняется делом в карточке.

## Быстрый старт

```bash
pnpm install
cp .env.example .env    # заполнить
pnpm build && node .output/server/index.mjs
```

Подключение к порталу и первая настройка — [`docs/DEPLOY.md`](docs/DEPLOY.md).

## Требования

Node.js 22+, pnpm 10 (версия — в `packageManager`). Публичный https-адрес для сервера.
Права приложения в портале: `crm`, `task`, `catalog`, `user_brief`, `placement`.

## Команды

| Команда | Что делает |
|---|---|
| `pnpm dev` | разработка |
| `pnpm check` | линт, проверка типов, тесты |
| `pnpm build` | сборка сервера |
| `pnpm test` | только тесты |

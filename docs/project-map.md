## Что мешает

- **Нет доступа к тестовому порталу из сессии агента.** Всё про REST сверено с документацией
  (MCP), но не с живым порталом — поэтому пункт 1 «Дальше» первый.
- **Предел `app.option` не известен.** По документации ядра — 2000 символов; пока не замерен,
  приложение считает по нему, и длинные свои промпты не сохранятся.

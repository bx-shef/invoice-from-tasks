# Что умеет приложение

> Last reviewed: 2026-10-29

Заполняет товарную часть счёта по задачам и затраченному в них времени.

## Где запускается

Откройте карточку счёта в CRM → верхняя кнопка → **«Заполнить из задач»**. Окно читает задачи и
пишет строки в счёт **вашими правами**: чужие задачи вы не увидите, в недоступный счёт не запишете.

## Что нужно настроить один раз

Администратор портала открывает приложение → **Настройки**:

- **Валюта ставок** и **ставки сотрудников** — без них счёт не посчитать.
- **НДС** для «Реквизитов вашей компании» — какая ставка ляжет в строки.
- **Округление** времени и **наценки** по тегам задач — по желанию.
- **Публичная страница** — если клиент должен видеть расшифровку счёта по QR-коду.

Разделы — в меню слева (Расчёт, Клиент, ИИ, Система). Сохраняет всё одна кнопка внизу: рядом видно,
что изменено и что не сохранится (например, ставки с ошибкой) — остальное сохранится.

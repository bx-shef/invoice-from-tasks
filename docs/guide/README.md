# Публичная документация

> Last reviewed: 2026-10-06

Этот каталог — **публичная** документация приложения «Счёт из задач»: её видят сотрудники портала
на странице «Справка» и по ней отвечает ИИ-чат справки. Остальное в `docs/` — внутреннее (правила
разработки, REST, выкат): на справку и в чат не попадает.

- Публичная страница — файл `NN-имя.md` в этом каталоге (номер задаёт порядок). Этот README на
  справку не попадает.
- Первая строка — `# Заголовок`, затем штамп `> Last reviewed`, затем одна строка описания.
- Разделы — `##` и `###`: по ним ИИ-чат подбирает фрагменты, а справка строит якоря.
- В FAQ (`90-faq.md`) у каждого вопроса — якорь `{#id}`: на него ведут ссылки «Что это значит?»
  в приложении (`HelpLink`). Якорь не меняем — его знает код.
- Ссылаться на внутренние документы (`../ARCHITECTURE.md` и т. п.) нельзя — гард `tests/repoGuards`.
